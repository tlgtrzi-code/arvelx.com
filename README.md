# ARVELX

## RVLX Kasa

RVLX Kasa, kurulum dosyası (installer) olarak dağıtılan bir masaüstü kasa
uygulamasıdır.

**Güncel sürüm:** v3.0.2

**İndir:** [En güncel sürüm](https://github.com/tlgtrzi-code/arvelx.com/releases/latest)

Kurulum dosyasını indirip çalıştırmanız yeterlidir.

## Bu depo hakkında

Bu depo yalnızca **genel dağıtım** için kullanılır. Kaynak kod burada
bulunmaz ve buraya kaynak kod eklenmez — kaynak kod özel (private) olarak
ayrı bir yerde tutulur.

Gelecekteki müşteri sürümleri de bu deponun **Releases** bölümünde
yayınlanacaktır.
